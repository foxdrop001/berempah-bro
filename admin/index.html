How this works (read once)

This dashboard edits one file, data/site.json, which is the single source of truth for the website's menu, outlets and promotions.

  • Save & Publish commits the file to GitHub. The change appears on the live site after the next site build. Ask your developer if it hasn't shown up.
  • Everything is checked before saving: bad postcodes, malformed prices or coordinates outside Singapore are blocked.

Connecting GitHub: create a fine-grained personal access token at github.com/settings with access limited to the effortxd/berempah-bro repository and Contents: Read and write permission. The token is stored only in this browser and never leaves it except to talk to GitHub. Use a private device, and revoke the token if the device is shared.
