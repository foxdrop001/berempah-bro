How this works (read once)

This dashboard edits one file — data/site.json — which is the single source of truth for the website's menu, outlets and promotions.

  • Save & Publish commits the file to GitHub. The site rebuilds and goes live automatically in about a minute.
  • Download saves the file to your computer instead, if a developer prefers to review it first.
  • Everything is checked before saving — bad postcodes, malformed prices or coordinates outside Singapore are blocked.

Connecting GitHub: create a fine-grained personal access token at github.com/settings with access limited to the berempah-bro repository and Contents: Read and write permission. The token is stored only in this browser and never leaves it except to talk to GitHub. Use a private device, and revoke the token if the device is shared.
